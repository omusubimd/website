ルビ構文を使用すると、任意のテキストの上にルビを振ることができます。

## 構文

### 基本的な記法

以下のように記述することで、ルビを振る対象となるベーステキストと、そのルビを表現できます。

```md
[藍色]<<あいいろ>>
```

ベーステキストを:symbol[\[]{name="左角括弧"}:symbol[\]]{name="右角括弧"}で囲み、直後にルビを:symbol[<]{name="小なり記号"}2つと:symbol[>]{name="大なり記号"}2つで囲んで記述します。
このとき、ルビはベーステキスト全体に対して振られます。つまり、上記の例では`藍色`というテキスト全体に対して`あいいろ`というルビが振られます。

文字ごとにルビを振りたい場合は、以下のように記述できます。

```md
[藍]<<あい>> [色]<<いろ>>
```

または、以下のような書き方もできます。

```md
[藍|色]<<あい|いろ>>
```

ベーステキストとルビがそれぞれ同じ数の:symbol[|]{name="縦線"}で区切られている場合、区切られたそれぞれの部分に対応するルビが振られます。上記の例では、`藍`という文字に対して`あい`というルビが、`色`という文字に対して`いろ`というルビが振られます。

ルビの:symbol[|]{name="縦線"}で区切られた部分に文字が含まれていない場合、対応するベーステキストの部分をスキップしてルビを振ることができます。

```md
[青天|の|霹靂]<<せいてん||へきれき>>
```

上記の例では、`青天`という部分に対して`せいてん`というルビが、`霹靂`という部分に対して`へきれき`というルビが振られます。`の`という文字にはルビが振られません。これは、以下のように記述することと同等です。

```md
[青天]<<せいてん>>の[霹靂]<<へきれき>>
```

## 備考
　このルビ構文は、いくつかの既存のルビ記法を参考に、よりマークダウンらしい形で表現できるように設計したものです。
　たとえば、[青空文庫注記形式](https://www.aozora.gr.jp/aozora-manual/index-input.html#ruby)では、ルビを二重山括弧`《 》`で示す方法が定められています。おむすび大作戦では、この二重山括弧の前にベーステキストを角括弧`[ ]`で囲むことで、ルビを振る対象となるテキストを明示的に指定し、またよりキーボードなどから入力しやすい小なり記号・大なり記号`<< >>`をルビの囲みとして採用しています。
　また、区切り文字`|`を使用してルビを文字ごとに振る方法は、[でんでんマークダウン](https://conv.denshochan.com/markdown#ruby)を参考にしています。
