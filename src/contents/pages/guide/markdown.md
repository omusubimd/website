---
title: マークダウンとは？
---

マークダウン（Markdown）は、文章に記号を添えて、見出しや箇条書き、リンクなどを表すための記法です。文書の構造や強調したい部分を、プレーンテキストで記述できます。

たとえば、行の先頭に `#` と半角スペースを書くと見出しに、`-` と半角スペースを書くと箇条書きになります。

```md
# 読書メモ

今月読んだ本の記録です。

- 小説
- エッセイ
- 技術書
```

マークダウンに対応したエディターやサービスでは、このテキストを見出しやリストとして表示できます。変換前のテキストでも文章の構造を読み取りやすいことが特徴です。

## マークダウンで文章を書く

マークダウンの文書は、通常のテキストエディターで作成できます。ファイルとして保存する場合は、一般に `.md` という拡張子を使います。

表示を確認しながら書くには、マークダウンのプレビュー機能があるエディターを使用します。文字の大きさや余白などの見た目は、表示するアプリケーションやサイトのスタイルによって変わります。

## 基本的な書き方

以下の例では、記号とその直後のスペースに半角文字を使用しています。

### 見出し

行頭に `#` と半角スペースを置きます。`#` の数で見出しの階層を表し、1個から6個まで使用できます。

```md
# 文書のタイトル

## 大きな見出し

### 小さな見出し
```

### 段落

段落と段落の間には空行を入れます。

```md
これは最初の段落です。同じ段落の中では、続けて文章を書けます。

これは次の段落です。
```

空行を入れずに改行した場合は、同じ段落として扱われます。その改行を表示に反映するかどうかは、使用する環境によって異なります。

### 箇条書き

行頭に `-` と半角スペースを置くと、箇条書きになります。

```md
- お米
- 海苔
- 梅干し
```

順序のあるリストには、数字に続けて `.` と半角スペースを使用します。

```md
1. お米を炊く
2. 具を入れる
3. 形を整える
```

### 強調

テキストを `**` で囲むと、強い強調を表します。通常は太字で表示されます。

```md
保存する前に、**内容を確認してください**。
```

### リンク

リンクとして表示するテキストを `[]` で囲み、直後の `()` にリンク先のURLを記述します。

```md
[おむすび大作戦のウェブサイトのソースコード](https://github.com/omusubimd/website)
```

### 引用

行頭に `>` と半角スペースを置くと、引用を表します。

```md
> ここに引用する文章を書きます。
```

### コード

文中のコードや記号は、バッククォート（`）で囲みます。囲まれた部分は、マークダウンの記法として解釈されずに表示されます。

```md
見出しには `#` を使います。
```

複数行のコードや記述例は、バッククォート3個の行で前後を囲みます。

````md
```
# この行は見出しに変換されません
```
````

## マークダウンの拡張とおむすび大作戦

マークダウンには、基本的な記法に加えて、表やタスクリストなどを扱う拡張があります。利用できる記法は、エディターやサービス、文書を処理するツールによって異なります。

おむすび大作戦では、日本語の文章表現のための拡張記法を定めています。基本的なマークダウンの書き方を踏まえたうえで、[ルビ](/syntax/ruby)や[字下げによる段落開始](/syntax/indent)の仕様を参照してください。これらの拡張記法を利用するには、対応する実装が必要です。
