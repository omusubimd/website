JavaScript / TypeScript 環境でのおむすび大作戦の利用は、remark プラグインがサポートされています。

## remark プラグイン

remark（および unified）エコシステムは、Markdown を処理するための JavaScript ライブラリです。おむすび大作戦は、remark プラグインとして提供されており、remark や unified を使用しているシステム・ツール等に組み込むことができます。

### インストール

```bash
npm install @omusubi-md/remark
```
